================================================================================

Tabs: Overview | Conversion | SKUs. Header: "TikTok Shop Financial Dashboard" /
"TikTok Shop metrics & performance analysis". DateRangePickerPro + timeframe (daily/weekly/…).

--- A) Overview metric cards (TiktokMetricCard × 4) — tiktokDashboardQuery → getTiktokMetadata → generateTikTokMetadata(timeframe) ---
API object TiktokMetadata (all numeric fields random per load):
  orders          — int, 150–400 * ceil(multiplier/7), multiplier from daily|weekly|monthly|yearly

  "Products" / "Total listed"     → products
  "Total Sales" / "Revenue"       → formatCurrency(revenue)

--- B) Conversion charts — TiktokConversionCharts (lg:col-span-5 on overview) ---

  - Chart type pills: Line | Area | Bar | Stacked (values: line, area, bar, stackedArea)

3) SHOPEE (ShopeeDashboardScreen — tab=shopee)
================================================================================

Tabs: Overview | Conversion (tab value "campaigns") | SKUs.

--- A) Overview metric cards ---
  Products card: hardcoded value 10 (ignores metadata.products 50–120)
  Total Sales: formatCurrency(metadata.sales) — sales 12000–25000 * m
  Orders: metadata.orders — 200–500 * ceil(m/7)
  Conversion: metadata.conversionRate.toFixed(2)% — 3.8–6.2
  Hidden in API: visitors 3000–8000 * ceil(m/3), products 50–120

--- B) ShopeeConversionCharts — synthetic quarterly series (NOT the 30-day table API) ---
useMemo formattedData: for each month index in selected quarter (3 points per Q1–Q4),
  iso = `${year}-${String(mi+1).padStart(2,'0')}-15`, date label = formatChartAxisDayNumber(iso)
  ym = year===2023 ? 0.8 : year===2025 ? 1.3 : 1.0
  seed = mi + year * 0.001
  visitors   = round((2500 + sin(seed)*800) * ym)
  orders     = round((130 + sin(seed*2)*40) * ym)
  conversion = round((4.8 + sin(seed*3)*1.2) * 10) / 10
  revenues   = round((6000 + sin(seed*1.5)*2000) * ym)
Chart series: visitors, orders, conversion, revenues (colors in chartConfig — orange family).
Chart types: same four as TikTok (line / area / bar / stackedArea). Years dropdown: 2023,2024,2025.

Static array monthlyData2024 (Jan–Dec) exists in file for legacy/alternate paths; the live chart uses the sin formula above.

--- C) List Conversion table — ShopeeConversionTable ---
Columns: Date | Revenue | Orders  (NO visitors / conversion % columns in UI)
Date: formatDateToMMDDYYYY
Revenue: formatCurrency(total_revenues) for admin
Overview: first 7 rows; Campaigns tab: pagination 20 rows, Previous / Next, "Page X of Y",
  Next on last page calls onLoadMore → parent decrements month range (more historical chunks).
Data: useShopeeConversionRate → generateShopeeConversionRate() — 30 rows:
  date, conversion_rate (3.2–6.5), total_orders (120–350), total_visitors (2500–6000),
  total_revenues (6000–15000)  [visitors & conversion_rate not displayed in this table]

--- D) Top Performing SKUs — ShopeeSkusTable ---
Columns (full tab adds Image first): Image? | SKU | Quantity | Revenue | Views | Stock | Status
  (Product name is NOT a column — only SKU code shown; name exists on entity for other use)
Per ShopeeSku: views, conversion_rate (2.5–8.5), stocks — views shown; conversion_rate not in table
Fixed 10 product names — SP-3000..SP-3009 (see dummy-data generateShopeeSkus)
